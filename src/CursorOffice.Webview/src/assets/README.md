# Brand assets

## `medielsoft-green-white.png`

- Purpose: complete MedielSoft logo mounted on the lounge wall opposite the sofa table.
- Original supplied directly by the MedielSoft project owner; the private source path is intentionally not recorded in the repository.
- Stored dimensions: 3000 × 3000 px.
- SHA-256: `478EBA74ADA62E1193AEC7AE3D717121CBCC4EA9F448D72329729BAB0843FECA`.
- Processing: none; the application keeps an exact copy and maps the full square without cropping.
- Rendering: transparent 1:1 wall-aligned plane, centred on the lounge partition and offset 8 mm from its front face to prevent z-fighting. It stays attached to the wall and follows the wall's natural perspective from every camera angle.
- Alpha handling: honoured exactly. The supplied file stores green RGB values even in fully transparent pixels; only the alpha-visible green brush circle and white wordmark are rendered, so no green square is introduced behind the real logo.

The MedielSoft name and logo remain a brand asset of their respective owner. They are not implicitly relicensed with the application source code.
